## About me

I'm a **software developer and Software Engineering student at ÉTS**, based in Montréal. I work on production web applications at **Loto-Québec** and co-founded **Northlify**, where I help turn real business needs into usable digital products.

I build software across **frontend, backend, and automation**, combining Vue, Nuxt, TypeScript, Node.js, APIs, and databases to deliver practical solutions. I also work on technical challenges involving infrastructure and applied AI.

I enjoy the full process: understanding a problem, making trade-offs, shipping a solution, and improving it based on how it works in practice.
